# The groove conservatory

Techno Mixing Station combines a New Orleans daiquiri factory with a lunar forest observatory. Cream enamel and aluminium frame the instrument; lime, orange and coral distinguish its musical controls. The panoramic window provides atmosphere above the functional controls, never behind editable steps or labels. The scene is decorative and conveys no live equipment status.

Asset: `public/assets/forest-moon-station.webp` (2048 × 683, WebP). Created with the built-in image generation tool, then encoded at quality 84 for delivery. No external paid API was used.

Generation brief: an ultra-wide, unlettered architectural panorama of a cream-enamel moon-base lounge with brushed aluminium, citrus daiquiri tanks at the edges, and huge rounded windows onto cypress, fern and pine in a glass habitat. Lunar terrain, black starfield and Earth beyond; warm interior light and cool forest light; playful, tactile, hopeful retro industrial design. No people or interface.

The image uses a responsive cover crop. Mobile retains the forest and reduces decorative typography. Control text uses solid surfaces; keyboard focus and reduced-motion rules remain available. The legacy studio retains its original appearance.
